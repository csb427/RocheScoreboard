# Roche Scoreboard

Roche Scoreboard is a Windows desktop scoreboard and broadcast presentation app for AFL and cricket.

Version **5.0 is in development**: full cricket mode and a redesigned control panel. See the [5.0 changelog](docs/CHANGELOG-5.0.md). A 5.0 download has not been published; the download below remains the latest published release.

## Download for Windows

### [Download Roche Scoreboard for Windows](https://github.com/csb427/RocheScoreboard/releases/latest/download/Roche-Scoreboard-Windows-x64.zip)

This link always downloads the latest verified Windows package. Do **not** download GitHub's automatically generated “Source code” ZIP.

1. Extract the whole ZIP.
2. Open the extracted **Roche Scoreboard** folder.
3. Double-click **Roche Scoreboard.exe**.

The download is self-contained. There are **no separate dependencies to install**: Visual Studio, the .NET SDK, the .NET Desktop Runtime, VC++ Redistributables and a separate VLC installation are not required. Keep the DLLs and the complete `libvlc` folder beside the EXE. Supported systems are 64-bit Windows 11 and Windows 10 version 2004 or newer.

If Windows shows a protection warning, confirm that the ZIP came from the official release page, select **More info**, then **Run anyway**. Code signing is the long-term way to replace this warning with a verified publisher identity.

See [USER_GUIDE.md](USER_GUIDE.md) for operating instructions. Release maintainers should follow [RELEASING.md](RELEASING.md).
