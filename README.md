# Roche Scoreboard

Roche Scoreboard is a Windows desktop scoreboard and broadcast presentation app for AFL and cricket.

## Download for Windows

Download the latest **`Roche-Scoreboard-v…-Windows-x64.zip`** from the [latest release](https://github.com/csb427/RocheScoreboard/releases/latest).

1. Extract the whole ZIP.
2. Open the extracted **Roche Scoreboard** folder.
3. Double-click **Roche Scoreboard.exe**.

The download is self-contained: Visual Studio, the .NET SDK and a separate .NET runtime are not required. Keep the DLLs and the complete `libvlc` folder beside the EXE. Supported systems are 64-bit Windows 11 and Windows 10 version 2004 or newer.

See [USER_GUIDE.md](USER_GUIDE.md) for operating instructions. Release maintainers should follow [RELEASING.md](RELEASING.md).
