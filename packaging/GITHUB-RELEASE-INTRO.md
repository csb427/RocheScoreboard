## Download and run

Download **Roche-Scoreboard-Windows-x64.zip** from the Assets section below. Ignore GitHub's automatically generated **Source code** ZIP and TAR files; they are not the Windows application.

1. Extract the entire downloaded ZIP.
2. Open the extracted **Roche Scoreboard** folder.
3. Double-click **Roche Scoreboard.exe**.

### Requirements

- 64-bit Windows 11, or Windows 10 version 2004/build 19041 or newer.
- No separate dependencies. The package includes .NET and VLC; Visual Studio, the .NET SDK, VC++ Redistributables and a separate VLC installation are not required.
- Keep every DLL and the complete `libvlc` folder beside the EXE.

If Windows displays a protection warning, verify that this is the official `csb427/RocheScoreboard` release, choose **More info**, then **Run anyway**.
