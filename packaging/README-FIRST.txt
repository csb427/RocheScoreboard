ROCHE SCOREBOARD — QUICK START
==============================

Supported computers
-------------------
• 64-bit Windows 11
• 64-bit Windows 10, version 2004 (build 19041) or newer

Visual Studio and the .NET SDK are NOT required.

Install and run
---------------
1. Extract the entire downloaded ZIP. Do not run the app from inside the ZIP.
2. Open the extracted "Roche Scoreboard" folder.
3. Double-click "Roche Scoreboard.exe".

Keep every DLL and the complete libvlc folder beside the EXE. The app is a
portable, self-contained folder; moving only the EXE will break startup and
video playback.

Your match saves and preferences are stored outside this folder, so replacing
the application folder with a newer release does not remove them. The app can
also download future updates from GitHub through Settings > Updates.

If Windows marks the download as coming from the internet, extract it before
launching. Production releases should ideally be code-signed so Windows can
identify the publisher.

Official downloads:
https://github.com/csb427/RocheScoreboard/releases/latest
